Jellyseerr is a free and open source software application for managing requests for your media library.
It is a a fork of Overseerr built to bring support for Jellyfin & Emby media servers!

## Seerr replacement

Jellyseerr and Overseerr have merged into Seerr. The
[configuration-only replacement plan](../../../docs/plans/seerr-migration.md)
uses a fresh Seerr instance; no existing Jellyseerr data needs importing.
