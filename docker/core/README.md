# Core services

Shared entry points and foundational services: Traefik, Homepage, CrowdSec,
Authentik, AdGuard Home, AdGuard Home sync and Kopia backups.

Directory categories organize Compose definitions; they do not determine Docker
project names, network names, data directories or dashboard groups. Preserve those
identities when reorganizing services. See [relocating services](../guidelines.md#relocating-services).
